## Open Files {#open-files}

Click **Files** in the sidebar or press <kbd>5</kbd>. Files lists attachments from mail on this device, including archived conversations. It is not a separate cloud drive or a complete index of every file on your mail server.

<ts-shot scene="files" alt="Files lists attachments with filters, a preview, and a link to the source conversation."></ts-shot>

## Find a File {#find-a-file}

1. Search by filename.
2. Narrow the list by sender, file type, direction, account, or date.
3. Select a result to see its details and source conversation.
4. Open or save the file, or follow the source conversation to read its context.

If a file is missing, [search for the email](search.html) first. Older mail may need an online server search before its attachments appear locally. **Mark Spam** removes that email's files from Files, and **Undo** restores them.

## Preview and Open Safely {#preview-and-open-safely}

On macOS and Windows, a selected safe file can show a preview above its details. Click the preview to open it. Linux does not have this preview backend. A missing preview can also mean the file's type or size is unsupported.

Risky attachments, such as programs, macro-enabled Office files, disk images, attached web pages, and disguised filenames, are never previewed. Opening them shows a warning and its reason. A preview or absence of a warning is not a guarantee that a file is safe.

## Star Files You Return To {#star-files-you-return-to}

Star a file to find it again quickly. Stars stay on this computer and are not transferred or replicated. Starring a file does not keep an offline copy or prevent the source mail from leaving the local cache. See [Privacy and Local Storage](privacy.html#keep-mail-on-this-device).
