summary: Every shortcut in ThreeStrands, generated from the same list the app's own Keyboard Shortcuts window uses.
---

Single-letter shortcuts work whenever you're reading and no text field has focus. Press <kbd>?</kbd> in the app to see this list, or <kbd>⌘/Ctrl + k</kbd> to search every command by name. On macOS, <kbd>⌘/Ctrl</kbd> means <kbd>⌘</kbd>; on Linux and Windows it means <kbd>Ctrl</kbd>.
