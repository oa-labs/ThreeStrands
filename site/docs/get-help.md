## Find an Answer {#find-an-answer}

Search these docs by feature, task, or symptom. Start with [Troubleshooting](troubleshooting.html) for missing mail, sending, drafts, calendar, and sync problems, or [Compatibility](compatibility.html) for provider and platform limits.

In the app, open the command palette with <kbd>⌘/Ctrl + k</kbd> and choose **Help and Documentation**. Settings pages also link to their relevant guide. Keyboard shortcuts are available with <kbd>?</kbd>.

## Report a Problem {#report-a-problem}

[Open an issue on GitHub](https://github.com/oa-labs/ThreeStrands/issues/new). GitHub requires an account to submit an issue. Include:

- The app version and operating system, including whether the machine is Apple Silicon, Intel, or x86-64.
- The affected feature and provider type, such as Gmail, IMAP, or Google Calendar.
- What you expected, what happened, and the shortest steps that reproduce it.
- Whether the provider's own app shows the same problem.
- A redacted error from **Settings → Diagnostics**, if relevant.

Review everything before posting: issues are public. Remove private message text, subjects, addresses, attachments, access tokens, API keys, passwords, storage credentials, join codes, and recovery phrases. A screenshot can expose unrelated mail; crop and redact it yourself before sharing.

## Report a Docs Issue {#report-a-docs-issue}

Use **Report a docs issue** at the bottom of any article. The link includes the page URL; describe the unclear step, missing answer, or wording that did not match your app. If your app version differs from the page's reviewed version, include that too.

## Data and Privacy Questions {#data-and-privacy-questions}

Read [Privacy and Local Storage](privacy.html), [Settings Transfer](settings-and-sync.html), and the [Privacy Policy](../privacy.html). No support process should need your password, API key, or sync recovery phrase.
