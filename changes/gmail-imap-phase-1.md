### Improved

- Connect Gmail with an app password from **Settings → Mail Accounts**. ThreeStrands fills in the server settings and lets you review which mailboxes to sync.
- Choose a default sending address and set Reply-To addresses for IMAP accounts.
- ThreeStrands can check Sent Mail after an interrupted send on IMAP accounts where the server keeps its own Sent copy.
- Gmail accounts connected over IMAP use Gmail’s conversation grouping when the server supplies it.
