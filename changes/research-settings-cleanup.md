### Improved
- Web research setup has moved from a separate dialog in **Agents** to **Settings → Web Research**. It now shows what is still needed before research can start, and lets you save each key and the storage agreement on its own.
- **Agents** replaces the "Delegated work enabled" checkbox with **Pause All**. While work is paused, a notice says how many tasks are waiting, and **Resume All** restarts only the tasks it paused.
